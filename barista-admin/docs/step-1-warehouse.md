# Отчет: Шаг 1 — Модуль «Товары / Склад»

## Что сделано:
1. **Модели данных в Rust:** Подключен крейт `rust_decimal` для точной работы с финансами и ценами без ошибок округления `f64`.
2. **REST API эндпоинты (`backend/src/main.rs`):**
   - `GET /api/products` — получение списка всех товаров с текущими остатками (`stock_quantity`) и зарезервированным количеством (`reserved_quantity`).
   - `POST /api/products` — создание нового товара в номенклатуре.
3. **Обработка ошибок:** Добавлена логика возврата корректных HTTP-статусов (200 OK, 201 Created, 400 Bad Request, 500 Internal Server Error) и логирование ошибок PostgreSQL.

## Текущая структура бэкенда (`backend/Cargo.toml` и `backend/src/main.rs`):
- Использованы крейты `axum`, `tokio`, `sqlx`, `serde`, `rust_decimal`.
- Все эндпоинты работают с пулом соединений PostgreSQL (`PgPool`).
