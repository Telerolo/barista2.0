# Отчет: Шаг 0 — Инфраструктура и Схема БД

## Что сделано:
1. **Авто-деплой (`deploy.sh`):** Интерактивный скрипт проверки Docker, запроса домена и почты, генерации секретных ключей и автоматического запуска через Docker Compose.
2. **Оркестрация (`docker-compose.yml`):** Настроены контейнеры PostgreSQL, бэкенда (Rust), Nginx (Reverse Proxy) и Certbot (автоматический SSL Let's Encrypt).
3. **Бэкенд-каркас (Rust + Axum):** Написан базовый сервер с подключением к пулу PostgreSQL через `sqlx` и эндпоинтом `/api/health`.
4. **База данных (`backend/init.sql`):** Созданы таблицы для пользователей (`users`), юрлиц (`companies`), кофемашин с QR-токенами (`machines`), склада товаров с поддержкой резервов (`products`), а также заказов (`orders` и `order_items`).
