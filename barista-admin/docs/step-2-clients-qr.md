# Отчет: Шаг 2 — Клиенты, Кофемашины и QR-коды

## Что сделано:
1. **Модуль юрлиц (Клиенты):**
   - Добавлены структуры данных и DTO для работы с таблицей `companies` (ИНН, КПП, юридический адрес, контактные данные).
   - Реализованы эндпоинты `GET /api/companies` и `POST /api/companies`.
2. **Модуль кофемашин и QR-токенов:**
   - Добавлена привязка кофемашин к клиентам (`company_id`).
   - При создании кофемашины через `POST /api/machines` автоматически генерируется уникальный `qr_token` (UUID v4), который в дальнейшем будет использоваться для сканирования и быстрого заказа с точки установки.
   - Реализован эндпоинт `GET /api/machines` для получения списка всех установленных аппаратов.
