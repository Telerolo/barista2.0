# Система управления складом и кофемашинами «Бариста»

B2B-платформа для поставщика кофе и расходников. Включает админ-панель, складской учет с резервированием, привязку кофемашин через QR-коды и автоматическую генерацию документов.

## 🚀 Архитектура и Стек
- **Backend:** Python (FastAPI), SQLAlchemy, PostgreSQL
- **Frontend:** Vue 3 (Vite, Tailwind / CSS-модули)
- **Инфраструктура:** Docker, Docker Compose, Nginx, Certbot (SSL)
- **UI/UX Стандарты:** 
  - Фиксированный сайдбар слева (100% высота, без глобального скролла).
  - Скролл только в правой контентной части.
  - Заголовок раздела строго по центру шапки правой части.
  - Кнопка «Назад» слева от заголовка при проваливании в подразделы.

  - Описание: Каталог товаров, остатки, цены, логика заморозки/резервирования (`reserved_quantity`), история движения.
  - 📄 Отчет о выполнении: [docs/step-1-warehouse.md](docs/step-1-warehouse.md) *(будет создан)*

  - Описание: Управление юрлицами, привязка кофемашин, генерация уникальных QR-кодов и макетов наклеек для печати.
  - 📄 Отчет о выполнении: [docs/step-2-clients-qr.md](docs/step-2-clients-qr.md) *(будет создан)*
