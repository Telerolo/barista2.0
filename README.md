# Система управления складом и кофемашинами «Бариста»

B2B-платформа для поставщика кофе и расходников. Включает админ-панель, складской учет с 2-этапным резервированием, привязку кофемашин через QR-коды, генерацию PDF-документов и быстрый запуск одной командой.

---

## 🚀 Архитектура и Стек

- **Backend:** Rust (Axum + SQLx + Tokio) — высокая производительность, надежная работа со складом и генерация QR/PDF.
- **Frontend:** Vue 3 (Vite + Tailwind / CSS-модули) — SPA с двухуровневой навигацией.
- **Database:** PostgreSQL (транзакции, строгий контроль резервов и остатков).
- **Infrastructure:** Docker, Docker Compose, Nginx (Reverse Proxy), Certbot (Let's Encrypt SSL).

### UI/UX Стандарты Интерфейса
- **Layout:** Двухколоночный. Левая часть (`Sidebar`) статична на 100% высоты экрана (`overflow-hidden`), без глобального скролла.
- **Scroll Region:** Независимый вертикальный скролл только внутри правой контентной области.
- **Header:** Заголовок текущего раздела строго по центру правой части шапки.
- **Navigation:** Кнопка «Назад» расположена слева от центрированного заголовка при переходе в подразделы.
- **Multiprofile:** Переключатель профиля/аккаунта размещен в самом низу левого сайдбара.

🗺 Пошаговый План Разработки (Roadmap)
​Каждый завершенный шаг документируется в директории docs/ и отмечается в списке.
​[ ] Шаг 0: Базовая инфраструктура и схема БД
​Описание: Интерактивный deploy.sh (домен + SSL), docker-compose.yml, структура базы данных PostgreSQL на SQLx, каркас Axum и Vue 3 Layout.

​📄 Отчет: docs/step-0-infrastructure.md
​[ ] Шаг 1: Модуль «Товары / Склад»
​Описание: Каталог номенклатуры, остатки (stock_quantity), зарезервированные объемы (reserved_quantity), ручная корректировка остатков и история движения.

​📄 Отчет: docs/step-1-warehouse.md
​[ ] Шаг 2: Модуль «Клиенты, Машины и QR-коды»
​Описание: Ведение юрлиц (реквизиты, ИНН), привязка кофемашин, генератор уникальных QR-кодов и выгрузка печатных макетов наклеек.
​📄 Отчет: docs/step-2-clients-qr.md
​[ ] Шаг 3: Модуль «Заказы» (Основной бизнес-процесс)
​Описание:
​Пайплайн статусов: NEW (резерв) -> CALL_PENDING (звонок клиенту) -> Подтверждение (окончательное списание со склада) -> SHIPPED -> COMPLETED (14 дней на оплату).
​Выбор формы оплаты (Наличный / Безналичный расчет).
​Генерация PDF-счетов и отгрузочных накладных.

​📄 Отчет: docs/step-3-orders.md
​[ ] Шаг 4: Модуль «Настройки и Профили»
​Описание: Создание пользователей панели (Админ, Менеджер), управление учетками, переключение активного профиля внизу левого меню.
​
📄 Отчет: docs/step-4-settings.md
​[ ] Шаг 5: Публичная страница заказа по QR
​Описание: Упрощенный веб-интерфейс для заказа расходников владельцем машины при сканировании QR-кода.

​📄 Отчет: docs/step-5-public-qr.md
